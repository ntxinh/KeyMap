# KeyMap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build KeyMap — a GTK4/Relm4 shortcut explorer that parses Niri/DMS, Ghostty, Fish, and custom TOML keybindings, detects conflicts, and generates Markdown cheat sheets.

**Architecture:** Single crate, single binary. Pure core (model, normalize, parsers, conflict, report) fully unit-tested; thin Relm4 UI on top; `notify` debounced file watching triggers full re-parse.

**Tech Stack:** Rust (edition 2021), relm4 0.9 (gtk4 + libadwaita), kdl 6, serde + toml, notify-debouncer-full 3.

**Spec:** `docs/superpowers/specs/2026-10-16-keymap-design.md`

## Global Constraints

- Target: Fedora 44, Wayland, Niri 26.x. Read-only — never writes to any config file.
- No database, no plugin system, no cloud anything.
- A parser that fails returns what it parsed; a missing binary/config yields `is_default` entries from an embedded fallback or nothing — never aborts the load.
- Cargo deps (pin in Cargo.toml): `relm4 = "0.9"`, `relm4-components = "0.9"`, `kdl = "6"`, `serde = { version = "1", features = ["derive"] }`, `toml = "0.8"`, `notify = "7"`, `notify-debouncer-full = "0.5"`. Dev-dep (Task 8): `tempfile = "3"`.

```rust
// model.rs
use std::path::PathBuf;


#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct Mods(pub u8);
impl Mods {
    pub const CTRL: Mods = Mods(1);
    pub const ALT: Mods = Mods(2);
    pub const SHIFT: Mods = Mods(4);
    pub const SUPER: Mods = Mods(8);
    pub const NONE: Mods = Mods(0);
    pub fn contains(self, m: Mods) -> bool { self.0 & m.0 != 0 }
    pub fn union(self, m: Mods) -> Mods { Mods(self.0 | m.0) }
}

#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct KeyCombo { pub mods: Mods, pub key: String /* normalized lowercase */, pub sequence: Option<Box<KeyCombo>> /* fish multi-key only */ }

#[derive(Debug, Clone, PartialEq)]
pub enum Source { Niri, Dms, Fish, Ghostty, Custom(String) }

#[derive(Debug, Clone, PartialEq)]
pub enum Context { Global, Terminal, Shell, App }

#[derive(Debug, Clone)]
pub struct Binding {
    pub combo: KeyCombo,
    pub raw: String,
    pub action: String,
    pub description: Option<String>,
    pub source: Source,
    pub origin: PathBuf,
    pub is_default: bool,
    pub context: Context,
}

impl Binding {
    pub fn sort_key(&self) -> String { format!("{}|{}", self.action, self.raw) }
}

impl std::fmt::Display for KeyCombo { /* "Ctrl+Shift+c", sequences as "a b" */ }
```

- Produces `normalize.rs`:
```rust
pub fn parse_niri_combo(s: &str, mod_key: &str) -> Option<KeyCombo>;
pub fn parse_ghostty_combo(s: &str) -> Option<KeyCombo>;
pub fn parse_fish_key(s: &str) -> Option<KeyCombo>; // single key token
pub fn parse_custom_combo(s: &str) -> Option<KeyCombo>; // same syntax as ghostty
```
